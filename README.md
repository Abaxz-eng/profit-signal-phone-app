# Profit Signal Phone App

Installable phone interface for closed-candle XAUUSD H1 signals.

This public repository contains only the sanitized user interface. It does not
contain the TradingView webhook token, phone enrollment code, MT5 credentials,
VAPID private key, account information, or automatic-trading configuration.

The GitHub Pages deployment is an interface preview. Live signal history and
push notifications connect through the separately hosted private API bridge.
